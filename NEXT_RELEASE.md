# Shutter Manager release requests

Implemented in 1.3.6 on 2026-11-08:

- Add the Vacation filter on the left at the same height as + Program. Show only programs whose vacation pause is disabled, without changing the actual vacation mode.
- Reduce spacing in expanded programs, including the gap before the first action and between actions.
- Hide both program sorting arrows and Copy program in the mobile layout up to 600 px. Keep the switch and Edit beside the name. Desktop sorting/copying remain available.
