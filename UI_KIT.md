# Shared UI provenance

Shutter Manager 1.5.2 bundles HA UI Kit 1.2.1 from v9h45n47mh-lab/ha-ui-kit, pinned to commit 78324b4f971b96ec198647a0ac08fcde1a0073d8. The original bundle, CSS, manifest and MIT license are copied unchanged into frontend/family-ui/1.2.1/ and verified by family-ui.lock.json. Prior fixed versions remain available for existing module URLs. No CDN or main/latest request is used at runtime.

Programs uses the shared programGroup, programRow and actionRow renderers. Font family, size, weight, line height, indentation, spacing and shared-control geometry are supplied exclusively by UI_CSS. The local Light Manager compatibility profile and all duplicate shared-component CSS were removed. Remaining local CSS only arranges cover-specific timetable, shading and assignment content; it uses UI Kit spacing tokens. Common editor, sensor, Settings, history, slider and help styles also come from the kit.

Behavior, stable-ID, translation, authorization and accessibility adapters preserve the application contracts. Compact switches use the native iconOnly option introduced in 1.2.1 and retain accessible names. Navigation, fields, select fields, multi-selection lists, weekday/season controls, buttons and native dialogs are rendered through shared components. Application data attributes and controlled changes are retained; the kit does not own configuration or permissions. Vacation mode remains in Settings.

The common-control flow also compares fields, select fields, Settings list text and dialog sections with an independent UI-only ShadowRoot in both themes. The program-layout browser test creates an independent ShadowRoot reference with only the original UI Kit CSS and its programGroup, programRow and actionRow output. No application CSS reaches that reference. It compares computed typography, indentation, spacing, controls and relative layout in light/dark themes at 320/390/1100 px, collapsed/expanded and admin/non-admin states. A static check rejects local rules targeting shared selectors or setting typography. Workflow screenshots and numeric measurements provide review evidence.

Automation, configuration protocol 7 and the 1.5-second tilt-to-height delay are unchanged. No Light Manager code or checkout is required.
